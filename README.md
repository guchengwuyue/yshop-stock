# yshop-stock 意象物质仓库库存管理系统

> Spring Boot3 + Vue3 · 物资进销存 · 出入库盘库闭环。面向中小企业仓管、采购与业务协同，把库存账做准、单据流程做规范、物资流转看得清。

**官网：** [https://www.yixiang.co/](https://www.yixiang.co/)

---

## 产品简介

yshop-stock 意象物质仓库库存管理系统，面向中小企业仓管、采购与业务协同场景，覆盖商品多规格、入库出库盘库、库存查询与时序追溯、单据审核/反审核及 A5 条码打印；入库 / 出库 / 盘库支持扫码枪条形码搜索，并联动客户与供应商档案。

**定位：** 建档 → 入库 → 出库 → 盘库 → 查询时序 → 条码打印

**适用：** 贸易商 / 门店仓 / 小型仓储中心

**核心能力：** 多规格 SKU · 扫码枪检索 · 审核/反审核 · 库存时序追溯 · 条码打印 · 客户/供应商档案 · 手机移动端（高级授权）

---

## 项目价值

让库存从「靠感觉」变成「有单据、有时序、可审计」的数字化管理。

| 价值点 | 说明 |
|--------|------|
| 账实一致 | 入库出库盘库联动库存，减少漏记、错记与账实偏差 |
| 流程可控 | 审核/反审核机制，关键单据变更留痕可追溯 |
| 规格精细 | 多规格商品管理，按 SKU 维度掌握库存余量 |
| 协同高效 | 客户与供应商档案一体，出入库业务衔接更顺 |

## 功能特性

围绕物资仓库日常作业闭环设计，覆盖建档、出入库盘库、扫码检索、条码打印与主数据管理。

| 模块 | 说明 |
|------|------|
| 商品管理（多规格） | 支持颜色、尺寸等规格组合，按 SKU 维护基础信息、条形码与库存维度，适配一品多规场景 |
| 商品入库 | 按供应商/来源创建入库单，支持扫码枪条形码搜索选品，明细到规格数量，审核后自动增加库存 |
| 商品出库 | 按客户/领用场景创建出库单，支持扫码枪快速定位商品，审核后扣减库存，避免无单据随意出库 |
| 商品盘库 | 按账面库存发起盘点，扫码录入实盘数量，自动生成盈亏差异并调整库存 |
| 库存查询 | 按商品、规格快速查看当前库存余额，支撑盘点、补货与业务询价 |
| 库存时序 | 记录库存增减变化轨迹，按时间线还原「何时、因何单、变多少」，便于对账与排查 |
| 单据 A5 条码打印 | 入/出/盘库单据支持 A5 打印，单据展示商品条形码，方便现场核验、签收与扫码复核 |
| 扫码枪条码搜索 | 入库、出库、盘库开单时可用扫码枪扫描商品条形码，快速检索并带入明细 |
| 审核 / 反审核 | 出入库与盘库单支持审核生效与反审核回退，兼顾业务纠错与库存账务一致性 |
| 客户管理 | 维护客户基础档案，出库业务可关联客户，便于统计去向与后续跟进 |
| 供应商管理 | 维护供应商信息，入库单可关联供应商，采购来源清晰可查 |
| 手机移动端（高级授权） | uni-app 支持小程序与 H5：入库、出库、盘库、库存查询等现场作业 |

## 解决的核心问题

| 痛点 | 解决方案 |
|------|----------|
| 库存账对不上？ | 以入/出/盘库单据驱动库存增减，结合审核机制与库存时序，让每一笔变动都有来源、可核对 |
| 开单选品慢？ | 入库、出库、盘库均支持扫码枪条形码搜索，扫一下即可带入明细 |
| 单据难留痕？ | 单据可审核/反审核，A5 打印支持条形码展示，线上流程与线下签收核验同步完成 |

**手工台账 → → → 单据化库存**
